Samsung S20 FE Droidian APT Repository

1. Add GPG key

curl https://mathew-dennis.github.io/adaptation-samsung-s20fe/s20fe-repo.gpg | sudo tee /etc/apt/trusted.gpg.d/s20fe.gpg

2. Add repository

echo "deb https://mathew-dennis.github.io/adaptation-samsung-s20fe stable main" | sudo tee /etc/apt/sources.list.d/s20fe.list
sudo apt-get update

3. Install adaptation

sudo apt-get install adaptation-samsung-s20fe
